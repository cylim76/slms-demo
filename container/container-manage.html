    primary_key: containerNo
    fields:
      containerNo:  { type: string, required: true, example: "MSCU1234567" }  # 箱号
      boxType:      { type: enum, required: true, values: ["20GP","40GP","40HQ","40RH"] }
      tare:         { type: int, required: false, note: "Tare 自重(kg)" }

      bookingNo:    { type: string, required: false, note: "Booking No；可为空" }
      requestKey:   { type: string, required: false, note: "整箱 Request 前缀（例如 2970）；可为空" }
      crpNo:        { type: string, required: false, note: "CRP/提箱单号；可为空" }
      truckNo:      { type: string, required: false, note: "车辆号码；可为空" }

      vendor:       { type: string, required: false, note: "运输公司" }
      carrier:      { type: string, required: false, note: "船公司" }
      pod:          { type: string, required: false, note: "目的港" }

      releaseDate:  { type: date, required: false, note: "提箱日期" }
      stuffDate:    { type: date, required: false, note: "计划装箱日期" }
      worksite:     { type: string, required: false, note: "作业地" }

      cntrStatus:   { type: enum, required: true, values: ["EMPTY","RELEASED","GATE_IN","STUFFING","LOADED","SHIPPED","HOLD"] }
      assignStatus: { type: enum, required: true, values: ["unassigned","assigned","corrected","cancelled"] }
      checkStatus:  { type: enum, required: true, values: ["none","pending","passed","failed"], note: "空箱检查任务状态（演示）" }
      dataQuality:  { type: enum, required: true, values: ["ok","suspect","conflict"] }

      correctedFrom:{ type: string, required: false, note: "若本箱为纠错后正确箱号：记录来源旧箱号" }
      correctedTo:  { type: string, required: false, note: "若本箱为纠错前错误箱号：指向正确箱号" }

      remark:       { type: string, required: false }
      updatedAt:    { type: int64, required: true, note: "更新时间戳(ms)" }
      history:      { type: array, required: false, note: "操作日志（演示结构）" }

  crp_done:
    description: "CRP 对应箱型完成量（演示：用于错误箱号更正时 -1）"
    primary_key: crpNo
    fields:
      crpNo: { type: string, required: true }
      doneQtyByType: { type: map, required: true, note: "例如 {20GP:1,40HQ:0,...}" }
slms-data-dict.md
字段/口径说明（Data Dictionary） 
# SLMS - 集装箱管理（container-manage）数据字典（v1）

## 1) container（集装箱）
- containerNo：箱号（业务主键，演示版允许修改；真实系统通常限制）
- boxType：箱型（20GP/40GP/40HQ/40RH）
- tare：Tare 自重（kg）
- bookingNo：Booking No（可为空）
- requestKey：整箱 Request 前缀（同一整箱可能对应多个型号行；此处用前缀聚合，演示用）
- crpNo：CRP/提箱单号（可为空；已配箱时通常存在）
- truckNo：车辆号码（可为空）
- vendor/carrier/pod：运输公司/船公司/目的港
- releaseDate：提箱日期
- stuffDate/worksite：计划装箱日期 / 作业地（为后续装箱计划使用）

### 状态枚举
- cntrStatus（箱状态）：EMPTY/RELEASED/GATE_IN/STUFFING/LOADED/SHIPPED/HOLD
- assignStatus（配箱状态）：unassigned/assigned/corrected/cancelled
- checkStatus（空箱检查）：none/pending/passed/failed
- dataQuality（数据质量）：ok/suspect/conflict

### 纠错字段（错误箱号更正）
- correctedTo：错误箱号 -> 正确箱号
- correctedFrom：正确箱号 <- 错误箱号

## 2) crp_done（CRP 完成量，演示口径）
- doneQtyByType：记录该 CRP 按箱型的“完成箱量”（演示）
- 错误箱号更正时，如果旧箱号满足：
  - assignStatus=assigned 且 crpNo 非空
  - 则对该 crpNo 的 doneQtyByType[旧箱号.boxType] 执行 -1（不小于0）

## 3) history（操作日志，演示）
- 每次编辑/批量修改/纠错，都追加一条：
  - ts：时间戳
  - action：动作（edit / bulk / correct）
  - note：说明
  - by：操作者（演示固定为 "demo-user"）

页面交互/约束（UI Spec） 
# SLMS - 集装箱管理 UI Spec（container-manage-v1）

## 1) 页面结构
- 顶部：标题 + 右上角版本号（可点击打开三件套）
- 左侧：筛选 + 列表（分页、多选、编辑、导出）
- 右侧：详情（关键字段、history、CRP完成量展示）

## 2) 默认滚动规则（全局）
- 所有列表/表格/列表视图根据画面大小自适应
- 内容溢出时自动出现滚动条：
  - 优先纵向滚动
  - 长行/宽表支持横向滚动

## 3) 查询
- 支持按：箱号/Booking/CRP/RequestKey/车辆/箱型/船公司/运输公司/POD/箱状态/配箱状态/空箱检查/数据质量/日期范围/作业地 筛选
- 查询后列表刷新，分页回到第一页

## 4) 列表操作
- 行点击：选中并在右侧显示详情与日志
- 多选：勾选复选框；支持全选（仅当前页范围）
- 批量修改：仅对选中记录生效（运输公司/状态等）；写入 history
- 导出CSV：导出“当前筛选结果（不受分页限制）”

## 5) 编辑（必须为页面内 Modal）
- 每行【编辑】打开页面内 modal（禁止 window.open / 浏览器新窗口）
- 可修改字段：箱号、箱型、Booking No、Tare、车辆号码、运输公司、船公司、POD、提箱日期、计划装箱日期、作业地、箱状态、配箱状态、空箱检查、数据质量、CRP No、备注
- 提供“箱号校验”按钮（ISO 6346 简化实现）

## 6) 错误箱号更正（在编辑 Modal 内）
- 勾选“错误箱号更正”后显示红色容器：
  - 新箱号输入 + 检查按钮
  - 检查：若系统已存在该新箱号 → 自动带入其字段（若有）；否则提示“无当前箱号”
- 保存更正时执行：
  1) 如果旧箱号 assignStatus=assigned 且 crpNo 非空：
     - 对 CRP 完成量 doneQtyByType[旧箱号.boxType] 执行 -1（不小于0）
  2) 转移空箱检查任务：checkStatus（及演示任务字段）从旧箱号转移到新箱号
  3) 旧箱号标记：assignStatus=corrected，correctedTo=newNo
  4) 新箱号标记：correctedFrom=oldNo，并承接旧箱号的 Booking/CRP 等字段（若新箱号不存在则创建）
  5) 双方写入 history

## 7) 三件套（SLMS-ThreeKitStyle）
- 布局固定：左侧导航（3按钮）+ 右侧单文档内容区（docCard + copy + pre）
- 内容区不够一屏时自动滚动（右侧优先纵向；pre/长行支持横向）
