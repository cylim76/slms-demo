# SLMS - CRP 发送管理（send-crp）数据字典

## 数据源
- localStorage['slms_crp_bookings_v1']（演示）
- 记录来自 CRP 录入页；本页主要负责“发送结果回写”。

## 关键字段
| 字段 | 类型 | 必填 | 口径/说明 |
|---|---|---:|---|
| bookingNo | string | Y | Booking No（业务主键；用于 query 自动选中） |
| carrier/vessel/voyage/etd | string/date | Y | 航次相关字段（展示/邮件生成） |
| gp20/gp40/hc40/rh40 | int | N | 箱量展示（邮件生成） |
| fileCount | int | Y | 附件数量（演示口径） |
| sendState | enum | Y | 未发送 / 已发送（本页写回） |
| vendor | string | N | 运输公司（本页写回；已发送应有值） |
| createdAt | int64 | Y | 录入时间（列表排序/展示） |

## 发送回写口径（演示）
- 点击“发送（示意）”后：
  - sendState = 已发送
  - vendor = 当前选择的运输公司
  - 保存回 localStorage
- 非演示系统应改为：后端写库 + 发送日志 + 审批/权限。

# SLMS - CRP 发送管理页（send-crp）UI Spec

## 1. 模式
- 完整模式：不带 embed=1
  - 左侧：CRP 列表（可筛选，横/纵滚动）
  - 中间：分割线可拖拽，宽度记忆
  - 右侧：发送面板
- embed 模式：?embed=1
  - 仅显示右侧发送面板（隐藏左侧列表与分割线）
  - 用于录入页 iframe 快捷发送

## 2. URL 参数
- booking=BKxxx：自动选中对应 Booking（优先最新 createdAt）
- mode=send|resend：影响面板提示文字与按钮文案（不改变回写口径）
- embed=1：进入 embed 模式

## 3. 发送面板
- 运输公司：下拉选择；用于写回 vendor
- 收件邮箱/标题/正文：演示字段；标题自动追加“船公司 + Booking”
- “重新生成正文”：根据当前选中记录 + 运输公司重新拼正文
- “发送（示意）”：
  - 写回 localStorage['slms_crp_bookings_v1'] 的该记录：
    - sendState=已发送
    - vendor=选择值
  - 写入发送日志到面板下方
  - postMessage 给父页面：{type:'SLMS_CRP_SENT', payload:{bookingNo,vendor}}（可选）

## 4. 关闭面板（embed）
- 点击“关闭面板”：
  - postMessage 给父页面：{type:'SLMS_CLOSE_SEND_PANEL'}
  - 父页面收到后关闭 iframe 弹窗并刷新列表

## 5. 左侧列表（完整模式）
- 筛选：Booking/船公司/船名/航次/状态/运输公司
- 行点击：选中并回填右侧发送面板
- 列表滚动：容器内横向+纵向滚动（sticky 表头）

## 6. 分割线
- 拖拽调整左右宽度
- 持久化 key：localStorage['slms_send_split_leftW_v4']（延续 v6 方案）
