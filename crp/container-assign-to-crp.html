结构唯一真源（Schema） 
version: slms-container-assign-to-crp-schema-v1
domain: slms
module: crp_container_assign

entities:

  crp_bl:
    description: "提箱单（CRP）主数据（演示内存数据 bls）。"
    primary_key: bl
    fields:
      bl:       { type: string, required: true, note: "提箱单号/提单号（演示字段）" }
      carrier:  { type: enum,   required: true, values: ["OOCL","MAERSK"] }
      vessel:   { type: string, required: true, note: "航次/船名航次（演示字段）" }
      etd:      { type: date,   required: true }
      vendor:   { type: enum,   required: true, values: ["中集","顺航"] }
      pod:      { type: enum,   required: true, values: ["LOS ANGELES","HAMBURG","BUSAN"] }
      country:  { type: string, required: true }
      quota:
        type: object
        required: true
        note: "箱型配额（演示：20GP/40GP/40HQ）"
      claimed:
        type: object
        required: true
        note: "已配箱计数（字段名沿用 claimed；语义=已配箱）"

  container:
    description: "箱号明细（配箱对象）。"
    primary_key: containerNo
    fields:
      containerNo: { type: string, required: true }
      releaseDate: { type: date,   required: true }
      vendor:      { type: enum,   required: true, values: ["中集","顺航"] }
      carrier:     { type: enum,   required: true, values: ["OOCL","MAERSK"] }
      pod:         { type: enum,   required: true, values: ["LOS ANGELES","HAMBURG","BUSAN"] }
      boxType:     { type: enum,   required: true, values: ["20GP","40GP","40HQ"] }
      bl:          { type: string, required: false, note: "已配箱时写入提箱单号" }
      status:      { type: enum,   required: true, values: ["unclaimed","claimed"], note: "未配箱/已配箱" }

operations:
  bind_atomic:
    note: "配箱并绑定（All-or-Nothing）：任何校验失败则全部不操作"
    checks:
      - "箱号不能已配箱（claimed）"
      - "箱号的 carrier/pod 与提箱单一致"
      - "箱型配额充足（claimed + need <= quota）"
    effects:
      - "container.status=claimed; container.bl=crp_bl.bl; crp_bl.claimed[boxType] += 1"

  unbind:
    note: "解绑：清空箱号的 bl，并回退提箱单 claimed 计数"
    effects:
      - "container.status=unclaimed; container.bl=''; crp_bl.claimed[boxType] -= 1 (>=0)"

  splitter:
    draggable: true
    persist_key: slms_demo_split_left_pct_v1

  edit_modal:
    note: "编辑不再新开页面，使用本页 Modal；保存后直接更新 containers 并刷新列表"
slms-data-dict.md
字段/口径说明（Data Dictionary） 
# SLMS - 提箱单（CRP）配箱（container-assign-to-crp）数据字典（v1）

## 1) 左侧：提箱单（CRP）bls（演示数据）
- bl：提箱单号（页面显示“提箱单号/提单号”）
- ship/carrier：船公司（OOCL/MAERSK）
- vessel：航次（演示字段）
- etd：开船日
- trans/vendor：运输公司（中集/顺航）
- pod：目的港（LOS ANGELES/HAMBURG/BUSAN）
- country：目的国家（由 pod 映射）
- quota：箱型配额（20GP/40GP/40HQ）
- claimed：已配箱计数（字段名沿用 claimed，语义=已配箱）

## 2) 右侧：箱号明细 containers（演示数据）
- no/containerNo：箱号（可编辑，保存时会自动转大写）
- releaseDate：提箱日期（yyyy-mm-dd）
- trans/vendor：运输公司
- ship/carrier：船公司
- pod：目的港
- type/boxType：箱型（20GP/40GP/40HQ）
- bl：已配箱时写入对应提箱单号
- status：unclaimed=未配箱；claimed=已配箱

## 3) 口径与校验
### A) 配箱并绑定（原子）
- 任一箱号已配箱 -> 全部失败
- 船公司/目的港必须与左侧提箱单一致
- 箱型配额：claimed + need <= quota

### B) 解绑
- 仅允许解绑已配箱箱号
- 解绑后：清空箱号的 bl，status=unclaimed，并回退提箱单 claimed[箱型]

### C) 编辑（本页弹窗）
- 允许修改：箱号/箱型/运输公司/船公司/目的港/提箱日期
- 保存校验（演示）：箱号非空且长度>=8
- 保存后直接更新本页数据；若箱号被改名，会同步更新选中集合与高亮行
slms-ui-spec.md
页面交互/约束（UI Spec） 
# SLMS - 提箱单（CRP）配箱 UI Spec（v1）

## 1) 页面布局
- 左：提箱单（CRP）查询 + 列表 + 抬头详情
- 右：箱号明细（配箱对象）查询 + 列表 + 多选操作
- 中间分割线可拖动调整左右宽度，并记住比例（localStorage）

## 2) 列表滚动默认规则（全局约定）
- 所有显示列表（表格/列表视图）根据画面大小自适应：
  - 内容溢出时自动出现滚动条（优先纵向滚动）
  - 宽表/长行支持横向滚动
- 本页：左侧明细、右侧明细、日志区、三件套内容区、代码块均按此规则实现

## 3) 选择与联动
- 点击左侧提箱单行：更新抬头详情，并刷新 Tab 标题
- 点击右侧箱号行：高亮；若已配箱则自动定位并高亮对应提箱单

## 4) 配箱并绑定（原子）
- 前置：必须先选中左侧提箱单，且右侧至少勾选 1 个箱号
- 校验失败：弹窗列出全部原因，且阻止全部操作
- 校验通过：将选中箱号全部绑定到该提箱单，并更新已配箱计数

## 5) 解绑
- 仅解绑已配箱箱号
- 弹窗确认列表后执行
- 执行后：清空箱号的提箱单号，并回退提箱单已配箱计数

## 6) 编辑（内嵌弹窗，替代新开页面）
- 入口：右侧每行“编辑”按钮
- 弹窗内可编辑：箱号/箱型/运输公司/船公司/目的港/提箱日期
- 保存校验（演示）：箱号不能为空，长度>=8
- 保存后立即刷新本页列表并高亮该箱号（如改名则同步更新选中集合）
