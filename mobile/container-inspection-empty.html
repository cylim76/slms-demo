slms-data-dict.md 字段/口径说明（Data Dictionary） 
# SLMS - 集装箱检查（空箱）

## 主档读取（slms_containers_v1）
- 本页只按 containerNo 查找主档
- 最终口径展示：
  - vendorFinal：最终运输公司（统计口径，以司机确认值为准）
  - tareWeightFinal：自重（最终，以司机确认值为准）
- 追溯展示（如字段存在）：
  - vendorByInspector/weightByInspector + inspectorAt
  - vendorByDriver/weightByDriver + driverConfirmedAt

## 检查记录（slms_container_inspections_v1）
- 一次保存生成一条独立记录（允许同箱号多条）
- photos：仅保存文件名列表（演示用）
- inspectionType：固定 empty（预留 future: stuffing 等）
slms-ui-spec.md 页面交互/约束（UI Spec） 
# UI Spec - mobile/container-inspection-empty

## 1) 检查入口
- 检查员输入箱号 -> 点击“查找”
- 查不到主档：
  - 仍显示该箱号（KV）
  - Toast 提示：去兜底录入创建记录
  - “兜底录入箱号/自重”按钮可跳转录入页

## 2) 兜底录入跳转（v2）
- 跳转到：mobile/container-entry-truck.html
- 带参数：
  - role=inspector
  - container=MSKU...
  - return=mobile/container-inspection-empty.html
  - ts=时间戳（防缓存）

## 3) 检查结果录入与保存
- 仅当主档存在时允许保存检查结果
- 保存：写入 slms_container_inspections_v1（unshift），列表显示最近20条
- 不更改主档“最终运输公司/自重”（最终口径由司机确认覆盖）

## 4) 回跳支持
- 支持 ?container=MSKU... 自动带入并触发查找
