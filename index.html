一、顶部导航规范（index-v16）

  1. 顶部导航仅显示：Simulation / R/Shipping / R/Booking / Stuffing
  2. 左上角仅显示系统 Logo 图片（img/trademark2.6babe1d4.png），不显示任何文字
  3. 顶部菜单采用“当前项下划线高亮”形式（参考截图）
  4. Stuffing 采用下拉菜单（支持二级菜单），点击子功能在系统内新建 Tab 打开页面

二、系统导航与页面打开规范

  1. 系统采用【页签式工作台（Tabbed Workspace）】作为核心操作形态
  2. 点击菜单功能项时，在系统内部新建 Tab 打开页面
  3. 同一功能页面如已打开，再次点击菜单应切换至已有 Tab
  4. Tab 标题默认显示功能名称，可动态追加关键业务编号

三、业务模块与功能归属说明（Stuffing）

  1. CRP录入：用于接收 FF 交接后的 CRP（提箱单）信息录入，并上传/归档 CRP 文件。
  2. CRP 发送：用于将录入完成的 CRP 信息/文件发送至指定对象并归档发送记录（页面：crp/send-crp.html）。
  3. CRP配箱：用于确定 CRP 与箱号之间的对应关系（装箱前置业务，页面：container/container-claim-with-bl.html）。
  4. CRP提箱现况RPT：用于按条件查询提箱进度/状态，并统计各运输公司未完成数量（页面：crp/rpt-crp-trans-status.html）。
  5. 集装箱信息维护：用于维护箱号、箱型、状态等基础信息。
  6. 装箱管理：用于装箱作业计划/进度管理（当前先占位，后续按实际页面补齐）。
  7. Mobile（二级菜单）：面向手机端的现场操作入口，鼠标点击/悬停 Mobile 后在右侧展开二级菜单。

四、文件命名与路径约定（重要）

  1. 页面文件名保持不变：演示阶段不在 URL/文件名上追加版本号
  2. 页面版本号仅用于：右上角版本标识 + 本弹窗“页面功能要求”同步维护
  3. 页面路径与目录结构需与正式开发保持一致

五、页面类型与打开方式规范

  1. 主业务页面使用系统内 Tab 打开
  2. 单条数据编辑采用弹出窗口（Modal）
  3. 编辑完成后主页面状态保持不变
