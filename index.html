一、顶部导航规范（index-v21）

  1. 顶部导航仅显示：Simulation / R/Shipping / R/Booking / Stuffing
  2. 左上角仅显示系统 Logo 图片（img/trademark2.6babe1d4.png），不显示任何文字
  3. 顶部菜单采用“当前项下划线高亮”形式
  4. Stuffing 采用下拉菜单（支持二级菜单），点击子功能在系统内新建 Tab 打开页面

二、系统导航与页面打开规范

  1. 系统采用【页签式工作台（Tabbed Workspace）】作为核心操作形态
  2. 点击菜单功能项时，在系统内部新建 Tab 打开页面
  3. 同一功能页面如已打开，再次点击菜单应切换至已有 Tab

三、业务模块与功能归属说明（Stuffing / index-v21）

  1. CRP录入：crp/crp-entry.html
  2. CRP 发送：crp/send-crp.html
  3. CRP配箱：crp/container-assign-to-crp.html
  4. CRP提箱现况RPT：crp/rpt-crp-trans-status.html
  5. 集装管理：container/container-manage.html
  6. 船舶管理：crp/vessel-manage.html
  7. 航次管理：crp/voyage-manage.html
  8. 装箱计划(normal)：stuffing/stuffing-plan-normal.html
  9. 装箱计划(Direct)：stuffing/stuffing-plan-direct.html
  10. 装箱计划(Pre)：stuffing/stuffing-plan-pre.html
  11. Mobile（二级菜单）：现场入口（mobile/*）
    1. 集装箱录入（拖车）：mobile/container-entry-truck.html
    2. 集装箱检查（空箱）：mobile/container-inspection-empty.html
    3. 装箱作业：mobile/stuffing-mobile.html
    4. 备货：mobile/picking.html
  13. Master（二级菜单）：船公司管理 / 作业地管理 / 设备管理（master/*）

四、文件命名与路径约定（重要）

  1. 页面文件名保持不变：演示阶段不在 URL/文件名上追加版本号
  2. 页面版本号仅用于：右上角版本标识 + 本弹窗“页面功能要求”同步维护
  3. 页面路径与目录结构需与正式开发保持一致

五、三件套弹窗样式固定（SLMS-ThreeKitStyle）

  1. 三件套弹窗固定为：左侧导航 + 右侧单文档内容区（docCard + copy + pre）
  2. 内容超出屏幕自动滚动：右侧内容区优先纵向滚动；代码块/长行支持横向滚动
  3. 所有列表/表格默认自适应并在溢出时自动滚动（优先纵向，宽表支持横向）
