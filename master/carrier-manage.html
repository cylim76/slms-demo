# --- Carrier Master (船公司主档) ---
# 演示存储：localStorage key = slms_carriers_v1（供 voyage-manage.html 下拉引用）
# 正式建议：table = slms_carriers

tables:
  slms_carriers:
    pk: id
    columns:
      id:        {type: string, required: true, note: "主键：CAR-xxx"}
      code:      {type: string, required: true, note: "Carrier Code，强唯一（建议大写）"}
      name:      {type: string, required: true, note: "名称（展示名），必填"}
      scac:      {type: string, required: false, note: "SCAC，可选"}
      country:   {type: string, required: false, note: "国家/地区，可选"}
      status:    {type: string, required: true, enum: [active, inactive], note: "inactive=软删除"}
      remark:    {type: string, required: false}
      createdAt: {type: int64, required: true, note: "毫秒时间戳（演示）"}
      updatedAt: {type: int64, required: true, note: "毫秒时间戳（演示）"}
    uniques:
      - name: uq_slms_carriers_code
        columns: [code]
    indexes:
      - name: ix_slms_carriers_status_updatedAt
        columns: [status, updatedAt]

slms-data-dict.md（字段/口径说明）

# Carrier Master 字段口径（slms_carriers）

- id：主键（演示：CAR-时间戳；正式：UUID/雪花ID）
- code：Carrier Code
  - 必填
  - 保存时建议统一大写（避免同义重复）
  - 全局强唯一（不区分 active/inactive）
- name：名称（展示名）
  - 必填
- scac：SCAC（可选，4位字母常见）
- country：国家/地区（可选）
- status：
  - active：启用（可被航次引用；下拉可选）
  - inactive：停用=软删除（禁止新引用；历史引用保留）
- remark：备注（可选）
- createdAt/updatedAt：毫秒时间戳（演示）

唯一性口径：
- code 全局唯一（不区分 status）

slms-ui-spec.md（页面交互/导出/入口）

# carrier-manage.html（carrier-manage-v2）

入口：
- Index -> Master -> Carrier Master（船公司管理）

查询：
- 关键词：匹配 code/name（不区分大小写）
- 状态：active / inactive / 全部

新增/编辑：
- 必填：code、name
- 保存校验：
  - code：强唯一（排除当前编辑记录）
  - 建议：保存时将 code 转大写
- 编辑时允许修改 code（仍需满足唯一性）

复制（新增增强）：
- 先点击列表行选中一条，再点击“复制船公司”
- 弹出新增窗口，默认带入：name/scac/country/status/remark
- code 默认清空（必须填写新 code）
- 保存时仍按 code 强唯一校验

停用/启用（软删除）：
- 切换状态需二次确认
- 停用后不删除记录，仅更新 status/updatedAt
- 口径：停用=软删除（保留历史引用）

导出 CSV：
- 导出“当前筛选结果”
- 字段：code,name,scac,country,status,updatedAt

数据存储：
- localStorage key = slms_carriers_v1（演示；供 voyage-manage.html 下拉引用）
