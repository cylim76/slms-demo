slms-schema.yaml（结构唯一真源）

# --- Voyage (航次) ---
# 演示版存储映射：localStorage key = slms_voyages_v1
# 字典引用：
# - slms_carriers (slms_carriers_v1)
# - slms_vessels  (slms_vessels_v1)

tables:
  slms_voyages:
    pk: id
    columns:
      id: {type: string, required: true, note: "VOY-xxx"}
      carrierId: {type: string, required: true, fk: slms_carriers.id}
      vesselId: {type: string, required: true, fk: slms_vessels.id}
      voyageNo: {type: string, required: true, note: "航次号(大写)"}
      pol: {type: string, required: true, note: "POL(大写)"}
      pod: {type: string, required: true, note: "POD(大写)"}
      etd: {type: date, required: true, note: "ETD 日期"}
      eta: {type: date, required: false, note: "ETA 日期（可空）"}
      cutoffAt: {type: datetime, required: false, note: "截关时间；为空时按 ETD-2天 12:00 估算"}
      status: {type: string, required: true, enum: [active, inactive]}
      remark: {type: string, required: false}
      createdAt: {type: int64, required: true}
      updatedAt: {type: int64, required: true}
    uniques:
      - name: uq_slms_voyages_carrier_vessel_voyage_etd
        columns: [carrierId, vesselId, voyageNo, etd]
    indexes:
      - name: ix_slms_voyages_etd_status
        columns: [etd, status]
      - name: ix_slms_voyages_cutoffAt
        columns: [cutoffAt]

slms-data-dict.md（字段/口径说明）

# Voyage 字段口径（slms_voyages）

- carrierId：船公司ID（外键）
- vesselId：船舶ID（外键）
- voyageNo：航次号（保存时转大写）
- pol/pod：港口（保存时转大写）
- etd/eta：日期（ETA 可空；若填，不能早于 ETD）
- cutoffAt（截关时间）：
  - 可空；用于“截关顺序/装箱顺序”管理
  - 默认估算：ETD-2天 12:00（仅在 cutoffAt 为空时自动生成）
  - 临近可用官方公布准确时间覆盖（手工录入优先）
- status：
  - active：启用（可被 Booking/Stuffing 等引用）
  - inactive：停用=软删除（禁止新引用；历史引用保留）

slms-ui-spec.md（页面交互/导出/入口）

# voyage-manage.html 交互规范（voyage-manage-v2）

入口/导航：
- Index -> Master -> Voyage Master（航次管理）

字典选择：
- 船公司/船舶必须下拉选择
- 下拉仅展示 active
- 若为空：先维护 carrier-manage / vessel-manage

查询：
- 关键词：匹配 船公司code + 船名 + 航次号（不区分大小写）
- 其它条件：carrier / vessel / POD包含 / ETD区间 / 状态

新增/编辑：
- 必填：carrierId、vesselId、voyageNo、pol、pod、etd
- 校验：
  - ETA 不能早于 ETD
  - 组合唯一：carrierId + vesselId + voyageNo + etd
- 截关时间 cutoffAt：
  - 用户可手工录入 datetime
  - 若为空：保存时自动填 ETD-2天 12:00
  - 若用户填了：以用户值为准，不覆盖

复制航次：
- 需先选中列表行
- 打开“复制航次”弹窗：
  - 默认带出字段
  - 提示用户修改 voyageNo / ETD（可选也改截关）

导出：
- 导出当前筛选结果 CSV
- 字段：carrier, vessel, voyageNo, pol, pod, etd, eta, cutoffAt, status, updatedAt
